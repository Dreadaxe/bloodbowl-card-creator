Créateur de cartes Blood Bowl

Créez, sauvegardez et imprimez vos cartes de joueurs, champions, cartes spéciales, dos de carte et tactiques de jeu.

L’éditeur fonctionne directement dans votre navigateur. Les cartes et préférences enregistrées localement restent sur votre appareil jusqu’à leur réinitialisation.

À propos des préréglages officiels

Certains préréglages reproduisent des données issues de publications officielles. Ils sont destinés aux personnes possédant les livres correspondants et ne remplacent pas les règles officielles.

Créer et modifier une carte

  1. Choisissez un éditeur dans la barre de navigation : Joueurs, Star Players, Cartes spéciales, Dos de carte ou Tactiques de jeu.
  2. Renseignez les champs ou chargez un préréglage. L’aperçu de la carte est mis à jour au fur et à mesure.
  3. Utilisez Sauvegarder comme image pour obtenir un PNG, ou Sauvegarder comme fichier pour conserver une carte modifiable au format JSON.
  4. Rechargez ensuite ce fichier JSON avec Charger une carte. La réinitialisation efface les données enregistrées localement pour repartir des valeurs par défaut.

Imprimer neuf cartes sur une feuille A4

  1. Depuis n’importe quel éditeur, cliquez sur Envoyer à l’impression. Pour les champions, vous pouvez aussi les sélectionner directement dans l’onglet Impression.
  2. Dans la feuille d’impression, choisissez et réorganisez jusqu’à neuf cartes par page. Vous pouvez revenir modifier une carte sans perdre votre sélection.
  3. Activez selon vos besoins les marques de coupe, la marge d’impression, les pointillés ou les angles droits.
  4. Imprimez au format A4, à l’échelle 100 %, sans ajustement automatique du navigateur. Vérifiez l’aperçu avant de lancer une impression recto verso.

Méthode historique avec GIMP

Cette méthode reste disponible pour composer manuellement une page :

  1. Installez GIMP.
  2. Ouvrez le modèle A4 au format XCF.
  3. Ajoutez les PNG avec Fichier → Ouvrir en tant que calques, puis placez-les dans les neuf emplacements.
  4. Réglez les marges à 0 dans la mise en page et imprimez à 100 %.

Versions et filiation du projet

Le projet est le résultat de plusieurs forks successifs. Chaque version conserve le travail précédent et ajoute ses propres évolutions.

Version Principales évolutions Liens
Barry Sheppard Création de la première version Blood Bowl, adaptée du générateur de cartes Warcry. Site · Code source
Graylikeme Poursuite de l’éditeur et ajout de la catégorie de compétences Devious. Site · Code source
Turficon Ajout des dos de carte, de l’internationalisation, de la traduction française et de diverses améliorations. Site · Code source
Noxoffa Séparation des éditeurs Joueurs et Star Players, ajout de 66 préréglages de champions de la Saison 3, nouveaux fonds et pictogrammes, thèmes clair/sombre, quatre langues et migration vers Bootstrap 5. Site · Code source
Dreadaxe — version actuelle Feuilles A4 de neuf cartes, file d’impression commune à tous les éditeurs, modification des cartes à la volée, persistance entre les onglets, marques de coupe et options de bordure, recherche de champions et travail de localisation française à partir des données BBTC.
